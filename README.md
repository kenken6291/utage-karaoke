```

├── index.html        … 画面（GitHub Pages）
```

## 1. スプレッドシート定義

`setup()` を実行すると、下記のシートと見出し行が自動で作られます（手作業での作成は不要）。

### `users` シート

| 列 | 項目名 | 内容 |
|---|---|---|
| A | email | メールアドレス（小文字で保存・書式は文字列） |
| B | passwordHash | SHA-256(salt + パスワード + PEPPER) の16進文字列 |
| C | salt | ユーザーごとのランダム値 |
| D | status | `仮登録` / `有効` / `停止`（手で「停止」にすると利用停止） |
| E | mustReset | TRUE のとき、次回ログインでパスワード再設定画面へ |
| F | nickname | ニックネーム（20文字まで） |
| G | character | ナビキャラ `mama` / `dj` / `pro` |
| H | failCount | 連続ログイン失敗回数（5回で15分ロック） |
| I | lockedUntil | ロック解除日時 |
| J | createdAt | 登録日時 |
| K | updatedAt | 更新日時 |
| L | lastLoginAt | 最終ログイン日時 |

### `favorites` シート

| 列 | 項目名 | 内容 |
|---|---|---|
| A | id | UUID |
| B | email | 持ち主のメールアドレス |
| C | videoId | YouTube動画ID（11文字） |
| D | title | 曲名 |
| E | artist | 歌手名 |
| F | keyShift | キーメモ（−12〜+12） |
| G | memo | 練習メモ（500文字まで） |
| H | isOhako | 十八番フラグ（TRUE/FALSE） |
| I | createdAt | 登録日時 |
| J | updatedAt | 更新日時 |

※ セッションは CacheService（6時間・アクセスごとに延長）で管理します。位置情報はシートに保存しません。

## 2. GAS のセットアップ

1. 新しいスプレッドシートを作り、「拡張機能 → Apps Script」を開く
2. `Code.gs` を貼り付け、プロジェクト設定で「appsscript.json をエディタで表示」をONにして `appsscript.json` も置き換える
3. **スクリプトプロパティ**（プロジェクトの設定 → スクリプト プロパティ）を登録

| キー | 必須 | 値 |
|---|---|---|
| `GEMINI_API_KEY` | ○ | Google AI Studio で発行したキー |
| `YOUTUBE_API_KEY` | ○ | YouTube Data API v3 のキー（既存の minna-aso プロジェクトのキーも流用可） |
| `APP_URL` | | 例 `https://kenken6291.github.io/utage-karaoke/`（メール本文に載る） |
| `TEXT_MODEL` | | セリフ生成モデル。既定 `gemini-2.5-flash`。より新しい Flash 系があれば差し替え可 |
| `TTS_MODEL` | | 音声合成モデル。既定 `gemini-2.5-flash-preview-tts`。新しいTTSモデル名に差し替え可 |
| `VOICE_MAMA` / `VOICE_DJ` / `VOICE_PRO` | | ボイス名の上書き（既定 Sulafat / Fenrir / Charon） |
| `AI_DAILY_LIMIT` | | 1人あたりのAI呼び出し上限（既定300） |
| `SPREADSHEET_ID` | | スタンドアロンのGASで作った場合のみ |
| `PEPPER` | 自動 | `setup()` が自動生成。**後から変えると全員ログインできなくなります** |

4. エディタで `setup` を選んで実行 → 権限を承認（メール送信・外部通信・スプレッドシート・Maps）
5. `testGemini` を実行し、ログにテキストと `TTS: audio/L16...` が出ればOK（`testGeocode` で逆ジオコーディングも確認可）
6. 「デプロイ → 新しいデプロイ → ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 表示されたウェブアプリURL（`…/exec`）を `config.js` の `GAS_URL` に貼る

> ⚠ **Code.gs を修正したら、「デプロイを管理 → 編集 → バージョン：新バージョン」で再デプロイ**しないと反映されません（URLはそのまま使えます）。

### YouTube APIキーの注意
GAS（サーバー）から呼ぶため、キーに「HTTPリファラー制限」を付けると失敗します。制限は「API の制限：YouTube Data API v3 のみ」にしてください。検索は1回100ユニット消費、1日の無料枠は10,000ユニットなので、通常検索とお出かけ選曲（1回で5検索）を合わせて1日およそ100検索が目安です。

## 4. バージョン管理

ログイン画面の下とアプリ画面の右下に「画面 vX.X.X ／ サーバー vX.X.X」が表示されます。

| 対象 | 場所 |
|---|---|
| 画面 | `index.html` の `<meta name="app-version" content="…" data-updated="…">` と、css/js 読み込みの `?v=…`（キャッシュ対策・同じ値にそろえる） |
| サーバー | `Code.gs` 冒頭の `APP_VERSION` / `APP_UPDATED` |

2桁目まで（例：1.2）が違うと注意文が出ます。3桁目（1.2.1 など）は画面だけの修正なので、サーバーは 1.2.0 のままで構いません。GASの再デプロイ忘れや、スマホのキャッシュで古い画面のままになっていないかの確認に使えます。

## 5. マイク・音声まわりの扱い

- **マイクはHTTPSでのみ使えます。** GitHub Pages はHTTPSなので問題ありません。ローカルで `file://` から開くとマイク・位置情報は動きません。
- 初回「マイクをONにする」でハウリング注意 → ブラウザの許可ダイアログの順に出ます。拒否した場合はアドレスバーの鍵マークから「マイク：許可」に戻します。
- エコーをかけるため、ブラウザ側のエコーキャンセル・ノイズ抑制・自動音量はOFFで取得しています。**イヤホン推奨**、スピーカー利用時は音量小さめから。
- Bluetoothイヤホンは遅延が大きく、エコーが二重に聞こえます。有線イヤホンが一番自然です。
- 「行こう！」待ち受けは、Android Chrome でマイクONと同時に使うとマイクの取り合いで止まることがあります。その場合はどちらか一方で使ってください。
- 「行こう！」からの自動再生は、iPhone Safari では自動再生制限で動画が止まったままになる場合があります。そのときは再生ボタンを1回押してください。
- Gemini音声は1セリフ数秒かかります。曲をセットした時点で曲紹介を先読みし、間奏の合いの手も再生開始時に先読みしています。待ち時間が気になる場合はヘッダーの「声」を「ブラウザ音声」に切り替えると即座に話します（セリフはGeminiが作ります）。
- 通信失敗やタイムアウト時は、キャラごとの定型セリフに自動で切り替わります。

## 6. 採点について
音程は判定していません。曲の再生中にマイクの音量を計測し、「歌っていた割合」「声量の安定感」「歌った長さ」から60〜100点の簡易スコアを出しています。マイクOFFのときは採点なしの講評になります。
